Нам нужно доработать компонент Exit (поднять контекст можно сделав запрос в NotebookLM) таким образом: Добавляются два свойства (галочки) в UI компонента: 1. Collider 2. Portal.  Если выбрано 1, то для активации выхода надо чтобы коллайдер Actor столкнулся с областью объекта на котором Exit, и тогда этого Actor телепортирует по указанному в компоненте адресу scene -> entry_id. Если это Triggerbox или Quad, то коллайдер это его область, если Entity, то коллайдер это штатная область коллайдера Entity если она задана.

Если выбрано 2, то для активации выхода нужно активировать (использовать) объект, для чего надо находясь в диапазоне reacheable игрок должен навести на объект курсор мыши и нажать. Когда переход по клику возможен, и мышь над объектом с Exit, то курсор мыши должен заменяться на тот же значок, что в subscene для области выхода из неё.

Может быть выбрано и 1 и 2, в таком случае телепортация возможна двумя способами.

Exit должен быть доступен любым Actor.  Вкачестве альтернативы клику мышью (недоступному для NPC) можно использовать команды GO или QUIT. Например: GO TO/THROUGH THE DOOR, или QUIT если выход из помещения лишь один, и QUIT THROUGH THE DOOR если выходов несколько, в том числе объект door. Этот способ доступен как игроку, так и NPC.

Объекты с EXIT должны включаться World builder в контекст сцены как для Parser, так и для Puppets Master, причём туда включается не только id целевой сцены (если это переход между сценами), но и Title сцены, если он есть. Парсер может использовать это название для альтернативных GO/QUIT команд, напр. GO TO LOBBY вместо GO TO DOOR. То же самое могут делать NPC.

Если способ 2 недоступен, NPC должны уметь использовать способ 1.

Также в UI компнента Exit добавляется кнопка Check котороая позволяет быстро проверить, валидно ли указанное сочетание scene_id -> entry_id этого компонента, то есть имеется ли такая сцена, такой Entry в ней и есть ли Title у целевой сцены (последнее не ошибка, но warning). Информация об успешной или неуспешной проверке показывается в Toast notification.
