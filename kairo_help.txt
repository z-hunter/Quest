Kairo тАФ Minimal, powerful task management.

Usage:
  kairo [command]

Available Commands:
  api         Headless API for external automation
  completion  Generate shell completion scripts
  export      Export tasks to JSON or Markdown
  import      Import tasks from JSON or Markdown
  sync        Sync tasks with Git repository
  update      Update Kairo to the latest version
  version     Show the current version
  help        Help about any command

Use "kairo help [command]" for more information about a command.
