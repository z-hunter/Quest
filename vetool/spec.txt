Нам нужен инструмент video export tool (vetool) для пакетного экспорта кадров из видео в атласы анимаций для игрового движка Scanline (всю нужную информацию про него ты получишь, сделав запрос к NotebookLM: `https://notebooklm.google.com/notebook/9f146be7-7c4a-4bb0-b7b4-7f20079e85b0`). Желательно, чтобы инструмент работал в браузере и использовал бэкэнд для работы с файлами, как это делает сам Scanline. Vetool запускается отдельно от Scanline, и не должен с ним конфликтовать, но может использовать его ресурсы. Впоследствии он может быть интегрирован в редактор спрайтов Scanline. 

## Функционал

 vetool должке уметь:

1. Загрузить MPEG-4 видео файл (мы работает с небольшими файлами не больше минуты длиной).
2. Можно перемещаться по отдельным кадрам анимации с помощью курсорных клавиш клавиатуры и видеть при этом точное время той точки, в которой мы находимся, а также номер кадра.
- Должна быть настройка кол-во кадров для перемещения (1= каждый кадр анимации, 2= через один, 3= каждый третий кадр и тд.). 
- Должна быть возможность установить текущий кадр (его временную отметку) как начало или конец выбранной области (области лупа). По умолчинию выбран весь файл.
- Клавиши Home и End переносят в начала или конец выделенной области. Ctl + Home/End переносит в начало и конец файла.

3. Можно воспроизводить по кругу либо весь файл, либо выбранную область. Старт/стоп воспроизведения = клавиша "пробел". Воспроизведение звука не критично и особо нам не надо.

4. Пользователь может создавать прямогольные области (рамки) на изображении. Он может рисовать рамку мышью, при этом отображаются её координаты и размеры в пикселях, которые можно в отдельных полях редактировать для точной подгонки/перемещения рамки.
Таких рамок может быть до 10.
Созданную рамку можно удалить.

5. Для каждой рамки пользователь может указать имя графического PNG файла из которых Scanline берёт спрайты и анимации а также номер колонки (каждый спрайт это колонка в PNG изображении, а его опциональная анимация это строки в PNG, идущие сверху вниз). Каждый спрайт имеет ширину и высоту, равные рамке из которой он экспорируется.

6. По нажатию на кнопку EXPORT происходит экспорт из каждой рамки кадров в указанную колонку в целевом PNG файлы (он пересоздаётся с нуля). Вполне возможно, что разные рамки будут создавать разые спрайты в одном и том же файле, главное чтобы номера колонок не конфликтовали.
- При экспорте испольются настройки выбранной области, то есть экспортируется фрагмент с заданными началом и концом, и с учётом настройки кол-ва кадров для перемещения (2= экспортируется через кадр и тд.)
